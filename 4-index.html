How to read it: every axis is a z-score within the selected season, flipped where needed so that farther out = better. Color uses the same within-season z-score of the chosen stat (blue = better, red = worse). Hover any dot for the raw numbers.
Data: nflverse player stats and Next Gen Stats, regular season. 2026 is through Week 12. Turnover avoidance uses actual turnovers (INT + sack fumbles lost) per dropback; turnover-worthy throws are not public. Sack avoidance is sack rate (sacks / dropbacks), flipped.
